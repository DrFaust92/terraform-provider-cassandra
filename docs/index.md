# Cassandra Provider

Manages Apache Cassandra keyspaces, roles and grants over CQL. Tested against Cassandra 4.1 and 5.0.

## Example Usage

```terraform
terraform {
  required_providers {
    cassandra = {
      source  = "DrFaust92/cassandra"
      version = "~> 1.2"
    }
  }
}

# Credentials and host can also come from the CASSANDRA_USERNAME,
# CASSANDRA_PASSWORD, CASSANDRA_HOST and CASSANDRA_PORT environment variables.
provider "cassandra" {
  username = "cluster_username"
  password = "cluster_password"
  host     = "localhost"
  port     = 9042
}
```

- `protocol_version` (Number) CQL binary protocol version.

- `use_ssl` (Boolean) Use TLS when connecting to the cluster.
- `username` (String, Sensitive) Cassandra client username. Can also be set with the `CASSANDRA_USERNAME` environment variable.
